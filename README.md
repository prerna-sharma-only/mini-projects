# Mini Projects

A collection of small projects built to practice and strengthen different concepts in **web development, backend development, authentication, databases, APIs, and JavaScript**.

Each project is maintained in its own folder with its own source code and documentation.

## How to Use

Clone the repository:

```bash
git clone <repository-url>
cd mini-projects
```

Then navigate to the project you want to run:

```bash
cd Secret-Key
```

Follow the instructions in that project's `README.md`.
